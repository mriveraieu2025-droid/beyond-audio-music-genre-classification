# Archived development work

This folder preserves the original exploratory Google Colab development notebook for *Beyond Audio: Music Genre Classification*.

- [`beyond_audio_colab_development.ipynb`](beyond_audio_colab_development.ipynb) contains earlier dataset inspection, exploratory modeling, intermediate experiments, and some superseded procedures.
- It is retained for research provenance, **not** as the recommended final reproduction workflow. Historical notebook outputs are not committed here, and a complete top-to-bottom run is not guaranteed.
- For the eight final and supplementary experiment notebooks, see [`notebooks/README.md`](../notebooks/README.md) and [`REPRODUCE.md`](../REPRODUCE.md).
- The archived notebook may require additional exploratory-only packages such as `scipy`, `Pillow`, and `requests`; these are intentionally omitted from the final notebook requirements. The final workflow may still install SciPy transitively through scikit-learn.

The archive preserves the original notebook content without changing its code or outputs.

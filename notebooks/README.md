
# Development Notebooks

## Overview

This folder contains the Google Colab notebook used
during the development of our machine-learning
project, Beyond Audio: Music Genre Classification.

Development began in Google Colab before the
GitHub repository was created.

## Development Process

The notebook documents several stages of the project:

1. Dataset exploration and preparation
2. Verification of experimental partitions
3. Audio-only and visual-only classification
4. Multimodal early-fusion experiments
5. Fixed and confidence-adaptive late fusion
6. Feedforward neural-network experiments
7. Prediction-level and visual-typicality analysis
8. Bootstrap confidence intervals
9. Robustness checks and result visualization

## Important Notes

The notebook contains exploratory and intermediate
experiments alongside analyses supporting the
final research report.

Saved outputs have been removed from this public
copy to reduce file size. The original Colab
notebook is retained separately.

The code uses data files and pretrained embeddings
stored in Google Drive. It is not yet configured
for independent execution without those files.

The repository will distinguish final experiments
from exploratory analyses and document the
dependencies required for reproduction.

## Development History

This notebook was developed in Google Colab
before being uploaded to GitHub in November 2026.

The GitHub commit history records changes made
